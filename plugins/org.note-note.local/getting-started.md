# A quick tour

**New Note** starts a page. **New notebook** adds a tab.

> Local notes save automatically in your notes folder.

## Make it readable

Select text, then use the toolbar: **bold**, *italic*, _underline_, ~~strikethrough~~ or ==highlight==.
Add tables and links from **Insert**. Paste images into a note.

- [x] Open your first notebook
- [ ] Write a note
- [ ] Sign in to OneNote, Sticky Notes or Notion from their tabs

| Shortcut | Action |
| --- | --- |
| `Ctrl+N` | New note |
| `Ctrl+Shift+P` | Commands and themes |
| `Ctrl+Tab` | Next notebook |
